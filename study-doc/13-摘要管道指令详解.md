# 13 - 摘要管道指令详解

> 核心源文件：
> - `packages/agent-core/src/harness/compaction/compaction.ts` — agent-core 摘要 LLM 调用
> - `src/agents/compaction.ts` — 摘要编排（chunk/merge/fallback）
> - `src/agents/agent-hooks/compaction-instructions.ts` — 语言保护兜底
> - `src/agents/agent-hooks/compaction-safeguard-quality.ts` — 质量审计 + 标识符保护
> - `src/agents/agent-hooks/compaction-safeguard-runtime.ts` — 运行时配置

---

## 整体调用链

```
summarizeInStages()
  │
  ├─ 消息太少或 token 不超限 → summarizeWithFallback()
  │    └─ summarizeChunks()
  │         ├─ buildCompactionSummarizationInstructions()
  │         │   （拼装 identifier 保护 + 自定义指令）
  │         └─ generateSummary() → LLM 调用
  │              System:  SUMMARIZATION_SYSTEM_PROMPT ...... 第 1 层
  │              User:    <conversation> 历史消息 </conversation>
  │                       <previous-summary> 旧摘要 </previous-summary>
  │                       基础摘要 prompt ................. 第 2/3 层
  │                       Additional focus: .............. 第 4/5/9 层
  │
  └─ 多个 chunk → merge
       └─ summarizeWithFallback()
            customInstructions = MERGE_SUMMARIES_INSTRUCTIONS ... 第 6 层
```

一共有 7 层提示词/指令，按序拼接。下面是每一层的完整原文、译文、输入输出和例子。

## 第 1 层：SUMMARIZATION_SYSTEM_PROMPT（系统提示）

**位置：** `packages/agent-core/src/harness/compaction/compaction.ts:426`

每次摘要 LLM 调用都会带上这条系统提示。

**原文：**
```
You are a context summarization assistant. Your task is to read a conversation
between a user and an AI coding assistant, then produce a structured summary
following the exact format specified.

Do NOT continue the conversation. Do NOT respond to any questions in the
conversation. ONLY output the structured summary.
```

**译文：**
```
你是一个上下文摘要助手。你的任务是阅读一段用户与 AI 编码助手之间的对话，
然后按照指定的格式生成结构化摘要。

不要继续对话。不要回答对话中的任何问题。只输出结构化摘要。
```

**输入输出：**

| 项目 | 内容 |
|---|---|
| 输入 | 系统提示（固定文本） |
| 输出 | 纯文本的结构化摘要 |
| 角色 | 固定为 system，每次调用都有 |

```
### Done
- [x] [Completed tasks/changes]
```

## 第 4 层：标识符保护指令（IDENTIFIER_PRESERVATION_INSTRUCTIONS）

**位置：** `src/agents/compaction.ts:38`

通过 `buildCompactionSummarizationInstructions()` 拼装后，作为 `customInstructions` 传入 LLM。

### strict 模式（默认）

**原文：**
```
Preserve all opaque identifiers exactly as written (no shortening or reconstruction),
including UUIDs, hashes, IDs, hostnames, IPs, ports, URLs, and file names.
```

**译文：**
```
保留所有不透明标识符的原始写法（不缩短、不重写），
包括 UUID、哈希值、ID、主机名、IP、端口、URL 和文件名。
```

### custom 模式

用户自定义标识符保护策略。通过 `wrapUntrustedInstructionBlock` 包裹安全标记后注入。

### off 模式

**原文：**
```
For ## Exact identifiers, include identifiers only when needed for continuity;
do not enforce literal-preservation rules.
```

**译文：**
```
对于 ## Exact identifiers，仅在连贯性需要时包含标识符，
不强制执行字面保留规则。
```

## 第 5 层：buildCompactionSummarizationInstructions（拼接层）

**位置：** `src/agents/compaction.ts:101`

将标识符保护 + 自定义指令合并为一个字符串：

```typescript
export function buildCompactionSummarizationInstructions(
  customInstructions?: string,
  instructions?: CompactionSummarizationInstructions,
): string | undefined {
  const identifierPreservation = resolveIdentifierPreservationInstructions(instructions);
  if (!identifierPreservation && !custom) return undefined;
  if (!custom) return identifierPreservation;
  if (!identifierPreservation) return `Additional focus:\n${custom}`;
  return `${identifierPreservation}\n\nAdditional focus:\n${custom}`;
}
```

**输出示例（strict 模式 + 自定义指令）：**
```
Preserve all opaque identifiers exactly as written (no shortening or reconstruction),
including UUIDs, hashes, IDs, hostnames, IPs, ports, URLs, and file names.

Additional focus:
Write the summary body in the primary language used in the conversation.
Do not translate or alter code, file paths, identifiers, or error messages.
```

然后在 `generateSummary()` 中拼入基础 prompt：

```typescript
basePrompt = `${basePrompt}\n\nAdditional focus: ${customInstructions}`;
```

## 第 6 层：MERGE_SUMMARIES_INSTRUCTIONS（合并摘要指令）

**位置：** `src/agents/compaction.ts:24`

**触发条件：** `summarizeInStages()` 把消息切了多个 chunk，各自摘要后需要合并。

**原文：**
```
Merge these partial summaries into a single cohesive summary.

MUST PRESERVE:
- Active tasks and their current status (in-progress, blocked, pending)
- Batch operation progress (e.g., '5/17 items completed')
- The last thing the user requested and what was being done about it
- Decisions made and their rationale
- TODOs, open questions, and constraints
- Any commitments or follow-ups promised

PRIORITIZE recent context over older history. The agent needs to know
what it was doing, not just what was discussed.
```

**译文：**
```
将这些部分摘要合并为一份有凝聚力的完整摘要。

必须保留：
- 正在进行的任务及其当前状态（进行中、已阻塞、待处理）
- 批量操作进度（例如"5/17 已完成"）
- 用户最后请求了什么以及正在如何处理
- 已做的决策及理由
- 待办事项、未解决问题和约束条件
- 任何已承诺的后续行动

最新的上下文优先于旧历史。代理需要知道它正在做什么，
而不仅仅是讨论过什么。
```

**输入输出示例：**

| 项目 | 内容 |
|---|---|
| 输入 | 多个部分摘要（每个是上一步 LLM 的输出） |
| 输出 | 合并后的完整摘要 |

**输入 3 个 chunk 摘要：**

```
[Chunk 1]
## Goal
分析 OpenClaw 上下文管理...已完成阅读 compaction.ts

[Chunk 2]
## Goal
...已阅读 preemptive-compaction.ts，理解溢出预检

[Chunk 3]
## Goal
...已阅读 tool-result-context-guard.ts，理解 midturn 预检
```

**输出：**
```
## Goal
分析 OpenClaw 的上下文管理机制

## Progress
### Done
- [x] 阅读 compaction.ts 压缩核心逻辑
- [x] 理解 preemptive-compaction.ts 溢出预检
- [x] 理解 tool-result-context-guard.ts midturn 预检

## Next Steps
1. 整理文档写入 study-doc
```

```
领导层级强化：
```

## 各层叠加关系总表

| 层 | 名称 | 叠加方式 | 位置 |
|---|---|---|---|
| 1 | SUMMARIZATION_SYSTEM_PROMPT | system prompt | 每次调用都有 |
| 2 | SUMMARIZATION_PROMPT | user message 末尾 | 首次摘要 |
| 3 | UPDATE_SUMMARIZATION_PROMPT | user message 末尾 | 增量更新 |
| 4 | 标识符保护指令 | 通过 `customInstructions` 传入 | strict/custom/off |
| 5 | buildCompactionSummarizationInstructions | 拼装 4 + 自定义指令 | 合并到 `Additional focus` |
| 6 | MERGE_SUMMARIES_INSTRUCTIONS | 作为 `customInstructions` | 合并多个 chunk 时 |
| 7 | Safeguard 结构指令 | `buildCompactionStructureInstructions` | 质量守卫模式 |
| 8 | HANDOFF_INSTRUCTIONS | `summarizeForHandoff()` | 模型切换 |
| 9 | DEFAULT_COMPACTION_INSTRUCTIONS | 兜底 | event + runtime 都没有时 |

**一次正常的摘要 LLM 调用的完整样子：**

```

<conversation>
User: ...对话历史...
Assistant: ...
Tool: ...
</conversation>

<previous-summary>            ← 如果有旧摘要（触发第 3 层）
## Goal
...
</previous-summary>

第 2 层或第 3 层的基础 prompt

Additional focus:              ← 第 4 层 + 第 5 层
Preserve all opaque identifiers exactly as written...

Additional focus:              ← 第 9 层（语言保护兜底）
Write the summary body in the primary language used in the conversation.
```
